# 种子域 · 辐射地图

**这三个是 embodied / agent / 数字人 / 世界模型类目标的默认种子**——因为它们几十年来就在解"在环境里表征、预测、行动、并显得可信"这一结构。**换一类目标就换种子**(标准不变:哪个非 AI 老学科最懂该目标的核心功能 / 约束。例:合同审查→法律对抗 / 审计 / 保险精算;供应链→运筹 / 物流 / 生态学)。下面的写法可直接照搬去给别的种子建地图。

每个种子给:**核心结构**(为什么它和目标是"结构近")、**子领域**(深度 1 邻居)、**三类辐射边**(深度 2 该往哪走)、**类比火花示例**。辐射深度封顶 2 跳。

---

## 种子 1 · 控制论 / 控制理论 / 状态估计

**核心结构:** 一个系统在环境里维持目标——感知状态、预测演化、反馈纠偏。**agent 本质就是一个对数字环境的控制回路;世界模型本质是个状态估计器。** 这是三个种子里"结构最硬"的一个。

**子领域(深度 1):** 反馈控制 / PID、最优控制、模型预测控制 MPC、卡尔曼滤波 / 状态估计、观测器设计、自适应控制、鲁棒控制、可控性 / 可观性、二阶控制论(观察者进入系统)。

**三类辐射边(深度 2):**
- **同机制:** 观测器 + 误差反馈、前馈补偿、增益调度、抗积分饱和。
- **同约束(实时 / 不确定下):** 传感器融合、延迟补偿、抗扰控制、稳定性裕度。
- **时间:** 祖先 = 瓦特调速器、维纳与艾什比的 cybernetics、伺服机构;后代 = 强化学习(其实是最优控制换了名字)、自动驾驶栈、机器人 MPC、数字孪生。

**类比火花示例:** agent"自我纠错" = 观测器 + 误差反馈;数字人"察言观色地调整语气" = 增益调度(按环境增益切换策略);"预测用户下一步" = MPC 的滚动预测。

---

## 种子 2 · 游戏引擎 / 仿真 / 游戏 AI

**核心结构:** 造一个持续存在的世界 + 一堆在里面自主行动的实体。**数字人 = 长大的 NPC;世界模型 = 可交互仿真;agent 的运行环境 = 游戏主循环。**

**子领域(深度 1):** 游戏主循环(tick / update)、物理引擎、行为树 / GOAP / 效用 AI、寻路(A* / 流场)、程序生成 PCG、NPC 记忆与日程调度、LOD 细节层次、网络同步 / 回滚、导演系统(如 Left 4 Dead 的 AI Director 动态调节节奏)。

**三类辐射边(深度 2):**
- **同机制:** 行为树、效用系统(utility AI)、黑板架构(多 agent 共享信息)、有限状态机、导演系统。
- **同约束(实时 + 可信 + 还得好玩):** 帧预算取舍、拟真 vs 好玩的平衡、涌现式叙事、"假装很聪明"的廉价技巧。
- **时间:** 祖先 = 文字 MUD、腹语式 NPC、Tamagotchi、模拟人生;后代 = 开放世界 NPC、生成式 agent 小镇(Stanford Smallville)、VTuber 直播、AI 队友。

**类比火花示例:** 数字人"无人值守时的自处" = NPC 的 idle behavior + 导演系统按空场调度;agent 团队协作 = 黑板架构;"让 agent 显得聪明而不真烧算力" = 游戏 AI 几十年的廉价拟智技巧。

---

## 种子 3 · 动画 / 木偶戏 / 戏剧即兴

**核心结构:** 让一个**合成的存在**显得活、可信、有意图、有注意力。**这是"数字人"形态的本体问题**,纯非 AI、表面离得最远、但直击要害。

**子领域(深度 1):** 迪士尼动画 12 原则(尤其 anticipation 预备动作、follow-through 跟随重叠、appeal 演技)、木偶操纵(focus / breath / 眼神引导)、即兴戏剧("Yes, and"、Del Close 的 Harold 结构)、方法派 / 斯坦尼体系、恐怖谷、拟人化设计、腹语、皮影 / 文乐、VTuber / Live2D 操演。

**三类辐射边(深度 2):**
- **同机制:** 呼吸与微动作制造"活着"、眼神 focus 制造"注意力"、anticipation 制造"有意图"、留白与停顿制造"在思考"。
- **同约束(被近距离盯着还得可信):** 恐怖谷规避、"低保真反而更可信"(卡通 / 木偶比逼真人形更被接受)、延迟下的即兴接话。
- **时间:** 祖先 = 文乐 / 皮影 / 腹语、迪士尼黄金时代;后代 = 皮克斯、VTuber、AI 伴侣 / 陪伴机器人。

**类比火花示例:** 数字人在"卡顿 / 思考"时用 anticipation 微动作掩盖延迟(木偶师的老手艺);"拒绝用户"时借即兴的"Yes, and"软化;刻意做成**略卡通**而非逼真,绕开恐怖谷。

## 二线种子(按形态需要再开,别一次全上)

- **认知科学:预测加工 / 自由能原理** —— 给"为什么预测式世界模型成立"一个第一性解释(大脑 = 预测机)。适合当理论骨架,不直接产形态。
- **经济学 / 机制设计 + 动物行为学(群体、共识素 stigmergy)** —— 多个 agent 怎么协作 / 不打架 / 涌现秩序。只有当靶是"多体形态"时才开。
