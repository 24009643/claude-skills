# 工程哲学 · engineering-philosophy

> 给**没有计算机科班背景、却在用 AI 写东西(Vibe Coding)的人**:让你看穿自己做出来的那个"能跑的东西"——它由哪几层拼成、**每一层是真的还是 AI 演给你看的、这次该把哪一层做成真的**。

一句话:它把"看着能跑就以为做完了"的黑箱,变成"我说得清每一层是什么、是真是假、下一步补哪"的透明盘。你的 Vibe Coding 会因此更**全面**(不漏掉任何一层)、更**具体**(每层都有判断,不再凭感觉)。

## 它解决的那个真问题

你不会写代码,对 AI 说"帮我做个 X",几分钟后界面出来了、能点、能显示,你以为成了。但你其实**看不见**这个东西内部分成哪几层,也**分不清**哪层是真做了、哪层只是 AI 为了"看起来正常"演给你的。于是你常常把一个**幻觉**当成**证据**——直到真用户一上手就露馅。

这个 skill 就是补上你缺的那副"透视眼镜"。

## 为什么它管用(第一性原理)

把"非科班的人 vibe coding 会翻车"这件事剥到底,你缺的其实只有三种能力,缺一不可:

1. **给每一层命名** —— 一个能跑的东西,是由 界面 / 连接 / 数据 / 权限… 几层拼起来的,每层干一件事。(不然你连"问题出在哪层"都说不出。)
2. **判断每一层是真是假** —— 这层是真做了,还是演的?(不然你分不清证据和幻觉。)
3. **判断每一层该做多真** —— 这次的目标下,哪层必须动真格、哪层可以先假着。(不然你要么白费劲,要么在该较真的地方偷工。)

这个 skill 给的正好是这三样:`mental-models` 教你 ① 和 ②(给每层命名 + 一句话验真),`SKILL.md` 的三阶段和作弊阶梯教你 ③,`failure-catalog` 把 ②③ 的失败做成可认的前兆。**三样凑齐,你就从"看不见"变成"看得穿"。**

## 一个实际例子

> **场景:** 你不会写代码,想用 AI 做一个「读书笔记」App——记下读过的书和心得,还能看别人的推荐。
>
> **没有这套工程哲学:** 你对 AI 说"帮我做个读书笔记 app",界面几分钟就出来了,漂亮,能加书、能显示。你截图:"我做了个 app!" 然后——朋友加了本书、刷新一下,没了;两个朋友同时用,看到了对方的私密心得。你以为做完了,其实手里是个**幻觉**。
>
> **用这套工程哲学,它带你逐层看清:**
>
> | 层(代表什么) | AI 给的是真是假 | 你自己就能验(一句话) |
> |---|---|---|
> | **界面**(你看到、能点的) | 真,做得挺好 | —— |
> | **连接**(界面到数据的那条线) | 多半假:数据写死在界面里 | 断网 / 关后端,界面还有数据吗? |
> | **数据**(存哪、活多久) | 假:只在内存里 | 刷新 / 重开,书还在吗? |
> | **权限**(每人只看自己的) | 没做:所有人共用一份 | 换个人登录,看得到你的笔记吗? |
>
> **然后它逼你回答一个问题:你这次到底要什么?**
> - 只想给人看个样子(**Demo**)→ 界面真、其余假,够了,别浪费时间建数据库。
> - 真想让人拿来记笔记(**MVP**)→ "数据"和"权限"这两层**必须**从假变真,否则用户第二天回来笔记没了、或看到陌生人的私密心得——你收集到的"有人爱用"全是假信号。(用现成后端如 Supabase,一下午能补上。)
>
> **结果:** 你从"看着能跑就以为成了",变成一句话说得清自己的东西——**"界面真、数据假,现在只能演不能用;要真上线,补'数据'和'权限'两层,约一下午。"** 这就是这个 skill 干的事:让不懂代码的你,也能**看穿每一层、分清真假、知道下一步补哪。**

## 为什么叫"工程哲学"

- **工程(思维)= 一套务实的工具:** 给每层命名、作弊阶梯、纵切一条线、标天花板、查根因。回答"**怎么做**"。
- **哲学 = 管总的那几条准绳:** 「你不是在写软件,你是在制造证据」「严谨度跟着阶段走,诚实度不跟阶段走」「作弊是聚焦,自欺是最贵的错误」。回答"**为什么、以什么心态**"。

工程给你工具,哲学给你"什么时候用哪个工具"的判断准绳。非科班的人最缺的不是工具(AI 能给),是这套准绳——所以它是**哲学**,不只是工程。

## 怎么用

**仅显式点名**——在 Claude Code 里输入 `/engineering-philosophy`,或说"用工程哲学 skill 帮我拆一下我这个 demo"。它**不会**因为你随口聊到 demo 就自动跳出来。带上你正在做的东西,它会当场按上面那套(哪个阶段 → 每层真假 → 该补哪层)给你判断。
